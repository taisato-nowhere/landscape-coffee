# 文言・画像の編集ガイド（LANDSCAPE COFFEE）

サイトの文章と写真は、**3か所だけ**覚えれば変えられます。ここを直して保存すれば反映されます。

| 変えたいもの | 触るファイル / フォルダ |
|---|---|
| ① 文章（見出し・キャッチコピー・ボタン文言など） | `src/i18n/ui.ts` |
| ② 中身のデータ（店舗・ニュース・ジャーナル・商品） | `src/data/content.ts` |
| ③ 写真 | `src/assets/images/` にファイルを置く |

> ⚠️ 文章は **日本語(ja)と英語(en)の両方**に同じ項目があります。日本語だけ直すと英語が古いままになります（英語が未定だと自動で日本語にフォールバックします）。

---

## ① 文章を変える — `src/i18n/ui.ts`

`ja:`（日本語）と `en:`（英語）のブロックに、同じキーが並んでいます。`"キー": "文章"` の **文章の部分だけ**書き換えてください。

代表的なキー:

| キー | 表示される場所 |
|---|---|
| `hero.title` | トップ最上部の大きなキャッチ（例「思い出を、重ねられる場所を」） |
| `hero.subtitle` | その下の小さな英文 |
| `brand.body` | トップの紹介文（`\n` が改行。1行ずつ表示されます） |
| `landscapes.title` / `news.title` / `journal.title` / `shop.title` | 各セクションの見出し |
| `footer.tagline` | フッターの一言 |
| `nav.about` ほか `nav.*` | ヘッダーのメニュー名 |

例（日本語のキャッチを変える）:
```ts
// 変更前
"hero.title": "思い出を、重ねられる場所を",
// 変更後
"hero.title": "ここに、新しいコピー",
```
英語側 `en:` の `"hero.title"` も忘れず直してください。

## ② 店舗・ニュース・ジャーナル・商品 — `src/data/content.ts`

それぞれ配列（リスト）になっています。**1件 = `{ ... }` のかたまり**。項目を書き換え・追加・削除できます。多言語の項目は `{ ja: "日本語", en: "English" }` の形です。

- **店舗** `stores`: `name`(店名) / `area`(住所) / `role`(役割) / `status`（`"open"` か `"coming_soon"`）/ `featured`（トップに出すか `true`/`false`）
- **ニュース** `news`、**ジャーナル** `journal`、**商品** `products`: 同じ要領で `title` / 本文 / 価格などを編集

新しい1件を足すときは、既存の `{ ... }` をコピーして中身を変えるのが安全です。`slug`（英数字のID）は他と重複しない値にしてください。写真は `slug` と同じ名前で③に置きます。

---

## ③ 写真を変える — `src/assets/images/`

**決まった名前でファイルを置くだけ**で、その場所に表示されます。置かなければ自動でプレースホルダになり、レイアウトは崩れません。詳しい一覧は `src/assets/images/README.md`。

ポイント:
- ヒーロー（最上部の大画像スライド）は `hero/main.jpg` が最初。`hero/02.jpg`, `hero/03.jpg` … と**置くだけ増え、消すだけ減ります**（ゆっくり切替わります）。
- 店舗写真は `stores/<slug>.jpg`（例 `stores/sakaide.jpg`）。
- 商品は `products/<商品のid>.jpg`、ジャーナルは `journal/<記事id>.jpg`。
- 形式は jpg / png / webp。**元画像は大きめでOK**（自動で軽量化されます）。

---

## 変更を本番サイトに反映する

このプロジェクトは **`main` ブランチに変更が入ると自動でビルド＆公開**されます（GitHub Actions）。

- **GitHubの画面で直接編集** → 鉛筆アイコンで編集して「Commit」すると、数分後に本番反映。
- **手元で編集** → 保存して `main` に push。
  - 反映前に手元で見るには: `npm run dev` を実行 → `http://localhost:4321/landscape-coffee/`

---

## もっとラクにしたい場合（次のステップ）

毎回ファイルを編集せず、**管理画面（ブラウザ）から投稿・編集**したい場合は、ニュース／ジャーナル／店舗を **microCMS**（無料プランあり）に、商品を **Shopify** につなぐ準備をします。表示側（このサイト）はそのまま、編集だけ管理画面に移せます。やるタイミングで声かけてください。
